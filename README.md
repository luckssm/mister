# Mister

> You make the calls. The match tells you why.

**Mister** is a football manager game where every decision has visible
consequences, and every match comes with a **súmula**, a match report that
explains why you won or lost.

In Portuguese-, Spanish- and Italian-speaking football, players call the
coach "Mister". In this game, that's you.

## Why

Football manager games tend to be either simple but disconnected (your
choices barely show up in results) or connected but opaque and heavy
(choices matter, but it takes hours to learn why). Mister aims for the
middle: few decisions, real consequences, results you can understand.

## Also: a framework experiment

This repo is also a testbed for building software with AI agents in a
structured, verifiable way: specs before code, invariant and statistical
tests, review agents, a risk report that tells the human which parts of a
change need eyes, and performance budgets. See `docs/process.md` and
`docs/experiments/`.
